# williamblake.ai

The holding page at https://www.williamblake.ai: William Blake, read beside the science of minds and machines. An independent project by Alexander Sabine, in preparation for 12 August 2027.

- `index.html` is the whole page: styles, words and the small script that carries the compasses out across the header.
- `img/` holds the plate (Library of Congress, Lessing J. Rosenwald Collection), the share card and the mark.
- Served by GitHub Pages from `main`. `CNAME` sets the address.
